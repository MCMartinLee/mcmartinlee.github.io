A free meeting availability poll app built to make group scheduling less annoying. Create an event, add candidate times across one or more days, share the link, and let attendees select every option that works for them.

## Live demo

- [Open FindTime](https://mcmartinlee.github.io/FindTime/)

## Source code

- [GitHub repository](https://github.com/MCMartinLee/FindTime)

## Why this tool

- Creates events with title, timezone, location, and optional directions.
- Supports Google Maps place search when a Maps API key is configured.
- Shows overlapping availability in a calendar-style view.
- Highlights popular time options and ranks choices with voter names.
- Uses hash routing for GitHub Pages-friendly sharing.
