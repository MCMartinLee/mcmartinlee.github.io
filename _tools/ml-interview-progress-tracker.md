A Firebase-backed static web app for keeping an ML interview sprint, job applications, interview notes, analytics, and exports in one focused dashboard.

## Live demo

- [Open the ML Interview Sprint Tracker](https://mcmartinlee.github.io/ml-interview-progress-tracker/)

## Source code

- [GitHub repository](https://github.com/MCMartinLee/ml-interview-progress-tracker)

## Why this tool

- Tracks a 25-day ML interview sprint with notes, checkboxes, and progress analytics.
- Syncs across devices with Firebase Authentication and Cloud Firestore.
- Includes dashboard metrics, weekly charts, a daily heatmap, and category views.
- Manages job applications with a drag-and-drop Kanban board and interview history.
- Exports data as JSON, CSV, or Markdown and supports JSON import.
